## 十一、路线决策记录（2026-07-24，与用户 grill-me 式拷问访谈确认，优先级高于 §八）

**终极目标**：挑战 1v9 Impossible（最高难度）。
**冲 1v9 的门票**：1v1 最高难度内置 AI，每张图 30 分钟内获胜、所有图零失败（"半小时"指每局时长，非总时长）。

**现状判断（用户原话浓缩）**：AI 目前是"瘸子"——进攻性特差、可以说没有战斗力；建造特别慢、规划乱七八糟；多 AI 配合"计划是这样但我没看见"；地图理解有大问题；运输机/登陆艇/飞行堡垒装载陆军/潜水艇潜浮/两栖飞机切换/核弹发射/反核建造/部分 T2 与实验单位直建/海军测试均未实现。

**地图理解备忘（用户口述的迷雾机制，阶段 1 要照此重修）**：单人迷雾=探索过就消散；多人迷雾分三种——无迷雾 / 同单人（探索过即消散）/ 必须有单位驻守否则重新覆盖。重新覆盖=浅黑色（记得覆盖前的敌方建筑），全黑=完全未探索（什么都看不见）。安全区域判定也不准。

**阶段排期**（依赖关系排序，用户认可"不赶时间、底子打好"）：
- 阶段 0：外部监控面板=总控台。第一屏只放"三角色在想什么"（计划书/工单/小队任务书）；要能发高层指令；游戏内设置面板的三角色启停开关搬上来
- 阶段 1：地图理解重修（迷雾三态 + 安全区判定）——所有决策的地基
- 阶段 2：建造提速 + 规划合理（治瘸子的腿）
- 阶段 3：进攻性 + 多 AI 配合可见可验（治瘸子的拳头）
- 阶段 4：套路补缺——核弹/反核进 1v9 套路（必需）；运输机/登陆艇/飞行堡垒/潜艇/两栖/T2 直建/海军明确暂缓
- 阶段 5：拿门票（最高难度全图 30 分钟零失败）→ 冲 1v9

**测试分工**：用户启动游戏与开局；进入对局自动触发数据记录；AI 负责分析与修复。不搞全自动跑局——瓶颈在 GUI 自动化脆弱（gui_step 曾搞崩游戏）与无人值守，不在 Kimi Code 权限。
**预算**：DeepSeek 预算充足不设限；但要求 LLM 输出别太离谱（控制无效输出）。
**观测形态补充**：赛后复盘报告与游戏内实时推送增强均未否定，排在总控台之后再说。

- 配比（几矿养一厂）：不写硬配比；42/s 只是单厂满产上限锚点，实战不会全程满产，4.3 实测校准

**百科喂法（治"一查 90s / 全塞爆 token"两难，用户痛点）**
报告Ⅲ方案照搬，**不需要再调研**：①常用单位卡片紧凑格式进 prompt 静态段（吃 KV cache，成本 1/10）；②LLM 决策所需状态（厂能产什么/队列/解锁表）由规则层算好随战报直接给，**消灭"查"这个动作**；③全量百科只留冷门查询口。

**小队打法：姿态标签制（用户拍板）**
- LLM 不打实时微操（20s 延迟打不了），只给每队**贴姿态**：顶住集火 / 风筝 / 保命；确定性层毫秒级执行具体走位（与反射层同一基础设施，只是姿态多几种）
- **任务带默认姿态，小队可改**（attack=顶住、harass=风筝、defend=固守）
- 反射层只做保命（受击撤退/残血拉开）；**新增：残血实验单位（蜘蛛/空堡）禁回防**（死亡核爆 4400/半径 200 伤己，报告Ⅶ实证）

**数值写死**
- **战力公式修正**（用户确认"目前确实有问题"）：GA 双属性单位次要属性 dps×0.5；乘射程修正 min(1.5, rng/150)；兑子决策改看 dps×hp/价

- **拆塔**：小队级默认禁冲塔阵（无炮兵不送死；看门狗催打前先查这条）；总指挥可拍板"**开磨**"（收入碾压或对面 360° 全龟时一波波换）；破阵菜单=**喷火机甲群（用户点名首选，需超级大量经济）**/导弹飞艇群/轰炸机一波流/实验单位
- **战略牌清单**：死亡核爆单位（蜘蛛/空堡）不进常规战力公式，单列明码标价给总指挥（无禁核时蜘蛛=不可拦截核爆 ×1）
- **总指挥怂=prompt 问题，随这批一起修**

**大军队 token**：三级分级汇报——小队看本队细节 / 军种中层看各小队一行汇总 / 总指挥看军种大数+重点事件，配区域战力聚合值。

**任务书改造（整包暂缓，姿态标签制跑一段后复评）**：验收四件套（end_state/time_limit/abort_criteria/weapons_status）、动词扩张（seize/clear/fix/screen/delay）、意图版本号+back-brief、预备队硬闸——全部挂起。
