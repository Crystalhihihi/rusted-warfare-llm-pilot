## 二十七、架构二期设计共识（2026-09-26 多轮拷问沉淀，实施照此；对话结论落盘）

**四级决策归属**（判据=状态变化速度 × 信息局部性；一题一题定，不拍脑袋）：

| 决策类型 | 例子 | 归宿 |
|---|---|---|
| 规则能写对的 | 抢占检测/补水/闸门/抢修派工 | 确定性层（毫秒~2s） |
| 规则写不对但选项能枚举 | 修理分诊/接战否/打哪个/中止否 | **Jev**（秒级，小候选集） |
| 选项枚举不出（开放规划） | 战略/布局/构成/进阶玩法拍板 | 慢层 CLI（分钟级） |
| 保命 | 受击撤退/残血拉开 | 反射层（毫秒） |

**铁律：模型只出意图，并行分发归系统。** LLM 输出=串行 token 流，让它直接驱动 N 队必然退化成连点收敛（所有单位走向最后点——用户实锤的病，结构性非 prompt 问题）；并行来自系统开 N 个窄循环/分发器（buildq 一人一队、v4.0 小队多线程都是此理）。token 爆炸的解法=聚合摘要（大团一行一群、落单独列、敌情挂地名），模型永远不看单位级全量。

**建造快层退役路径**（§二十五"取消模型"的前提与顺序）：生成器泛化（现仅防线密集阵→工厂区/后勤排/矿区围合/沿崖绕资源簇变体）+ 选址菜单（先验蒸馏+现状热区）补齐 → 建造 chat ×4 判断归零 → 退役，BuilderManager 直派（16s/单吞吐账随模型出回路消失）。**没补齐前建造 chat 是止血带，不提前撕。**
**抢占/修理形态**：确定性事件检测（池安稳/前沿推进，现成）→ **默认动作立即执行（零模型）→ 慢层下轮否决/改派**——"先默认干、慢层修正"代替"问慢层再干"，抢占窗口期就是这么抢的。修理分诊=打分规则（战略价值×受损度÷距离）先行，不够处才 Jev Choice 小题。
**进阶玩法**（空降/蜘蛛飞艇自爆/核/潜浮）=**慢层按名调用"操作包"**（打不打、打哪），确定性层出脚本化序列（装载→运输→空降；蜘蛛走位→引爆），快层/反射**只有中止权**（运输要坠→提前卸）。0.3s 快层无权决定扔核弹/送蜘蛛（死亡核爆 4400 伤己，P:323）。

**地图蒸馏器**（治"AI 对地图理解一直有问题"；用户定调：像人类一样赛前研究图，先做官方图）：
- **原则：事实静态化，判断动态化。** 蒸馏文件只放不会动的：出生点（spawns.py 现成，敌家按出生点不猜方位）/资源簇命名/隘口（chokes 现成）/走廊宽度/水域分布/禁区（水道/交战走廊——b_seaFactory 水道中央就是缺这条）。"现在哪里在打"永远运行时现算，**静态标"交战区"=standing order 毒药**（用户实锤：中路实控后 AI 会死守标记位；与"敌强我弱勿硬拼"抗命借口、节奏基准变紧箍咒同病）。地理派生事实可写（"南矿孤立无掩护"），**不写处方**（"勿早开"）。
- 形态：离线蒸馏官方图入库（按图名+rows hash 索引，开局加载进固定头吃缓存）；**同一套代码运行时兜底生成**未蒸馏图（自制图）。蒸馏文件=地名表+地形事实（文字事实，不是 ASCII 格——LLM 读格差已证实）。
- **地名同时是 LLM 的输出词汇表**：`attack 北矿`/`position 隘口A`→系统解析坐标+合法表校验（治 LLM 坐标无能，与建造锚点合法表同构，探针已证"从合法表选点"满分）。
- 回放热区（115 局语料）**只当蒸馏器的测试集**（验证锚点命名与人类交战/建造热区重合度），不进 prompt 内容。
- LLM 看菜单不看地图：建造看选址菜单（安全池/推荐锚点/槽位占用），不看全图。

**code CLI 慢层**（总指挥先 A/B，再建造指挥；军种中层带查询预算最后）：
- 目录：`资料库/`（pedia/maps/tactics 持久，`--add-dir` 挂入）+ `局/<对局id>/`（state.md 每拍重写/plan.md 自己写改/notes/ 跨轮笔记/out/decision.json）。**换局重置整个 bug 类=换文件夹**；文件夹即对局档案（审计友好）。
- 边界：CLI 只读文件写决策，**不碰游戏**；守卫/闸门/事件召唤节拍/Jev 全部留在 bridge。决策输出=decision.json 走既有翻译守卫。
- 文档实证（kimi-code-docs）：`kimi -p` 无头+`--output-format stream-json` 可程序解析；`type="openai"`+自定义 base_url **留 DeepSeek 模型**（文档点名 DeepSeek/Qwen 开箱）；`--agent-file` 绑角色系统提示；常驻会话走 `kimi web` REST API（免每轮起进程）。
- **前置工序**：state.md 摘要（§二十五同源的群聚合+落单；先修"造不好"再量"乱"）。CLI 化的账：调用变多×单次 prompt 变小，净账从第一个原型起就记 token（stream-json 可采），A/B 几局再定全换。

**Jev 接入边界**（沿用 §二十四+本轮加固）：Jev 只答"现场可行性"（Noul/Choice/Score），打不打归任务书+执行层政策（分歧进日志不静默抗命）；note 汇报由确定性层从"任务+答案+动作序列"模板化生成；看门狗从兜底代打退化为故障保护；校准按原语分别标定（Noul 0.012/Choice 0.086/Score 0.254）；灰度 `squad_engine=jev|chat` 一键切回。
