## 〇、结论速览

1. **"乱"不是判断问题，是确定性层的三个问题**：几何生成只覆盖防线一种形态 / 闸门被绕过导致规则层自己乱盖 / 三方抢占位互相打架。
   这一点项目自己已经定过案——`P:375` ①（用户审过的架构结论）：**"AI 不懂整齐也不需要懂——整齐=生成器几何（837 座样本参数），模型只挑点。"**
2. **"从来没有视觉设计"这句判断成立，但 RTS 里的"视觉设计"其实是三件可算的事**：几何、可达性与合法性、保护关系。
   其中**保护关系已经量过**（`P:439`），**几何与可达性一个指标都没有**。
3. **最大缺口：现在没有量"乱"的指标。** 现有四个指标（遮盖率/裸奔率/穿插率/护矿率）量的是**功能关系**，不覆盖"整齐"本身——
   所以每次治完，判据仍只能凭肉眼一句"**实在太乱**"（`P:351` 用户原话，且这直接导致了脚本防线/哨戒/维修湾被一把全砍）。
4. **推进顺序**：先量（加指标、取人类靶子）→ 再泛化生成器 → 再升级选址判据 → 顺手补闸门漏。
5. **状态：待做，零实施。**

## 一、"乱"的三个来源（每条附行号实证）

### 1.1 几何生成只覆盖防线一种形态

| 项 | 现状 | 证据 |
|---|---|---|
| 已有的生成器 | `_formation` + `defense_sample` 参数：100px 节距垂直敌向成线、防空压后排 120px、主通道留空、逐点占位/可达校验、落子即占 | `P:351` |
| 架构定位 | 整齐=生成器几何（**837 座人类样本参数**），模型只挑点 | `P:375` ① |
| 槽位网格（fp 占地表驱动） | 厂区贴死密排、防线弧格距=建筑宽+3 格、防空压后排不占弧尖、主通道留空、内圈维修湾、后勤成排、海厂近水；占位图含在途/判死格 | `P:366` |
| **缺口** | **厂区/后勤/制造仪群/池群/维修湾都没有几何生成器**，靠槽位网格 + 安全值"顺延"落子 | `P:351` / `P:366` |
| 落子判据的固有缺陷 | 槽位安全值择优：**argmax 小窗口在 400px 格控制图上无梯度**（相邻候选共享邻域），必须"顺延"跨威胁边界 | `P:230` |

→ 安全值驱动的选址天然是"东一榔头西一棒"：它只回答"危不危险"，不回答"整不整齐"。这是屏幕上"歪歪扭扭"的直接来源。

### 1.2 闸门被绕过 → 规则层自己乱盖

| 现象 | 实锤 | 证据 |
|---|---|---|
| 计划书说"不上海军"，规则层照盖海厂 | **`b_seaFactory@(3430,2190)` 盖在水道中央** | `P:491` 未完成① |
| 支持建筑跑出防线外盖 | 坐标单实控闸原只罩 `b_extractor*`，LLM 给工厂写精确坐标**就绕过闸**；已扩到全部非防守类建筑 | `P:400`（§十六） |
| 选址失败只有"拒"没有"挪" | pool:1/2 敌出生点 520px 自杀扩张、factory:1/2 贴家被杀——定性为**正确否决**，要减的是"**系统只会拒不会挪**" | `P:229`（阶段 2 增补） |

### 1.3 三方抢占位 → 落点互相打架

| 现象 | 证据 |
|---|---|
| 抢单位控制权嫌疑（规则层 / 队长 / 小队三方派单） | `P:377` ③ |
| 同拍抢同一建造者（tick 内先抢修后 routine，同一建造者一拍被派两单） | `P:385` |
| 撞点（阵地展开与 `defense:k` 不共享占位，已撞一例） | `P:357` ② / `P:370` |
| wo_id 重排假账（`set_work_order` 全量替换后 idx 从 0 重排 → 派单/落账错位） | `P:386` |
| 安全机制三层不一致（执行层有防线圈豁免、反射层没有 → 互相否决，防线永远起不来） | `P:104` |
| 抢修派工风暴（4 塔 12 建造者循环抢占） | `P:355` |
| 编辑器单位污染（`editorOrBuilder` 被当空闲建造者，**所有派发扔进虚空**） | `P:275` |
| 假接管（`last_act` 原只认"成功发指令"，hold/等钱不算活着） | `P:372` / `P:419` |

→ 这一栏里**每一条在画面上都会表现为"乱"**，但全部是确定性 bug，与模型判断无关。

## 二、"视觉设计"在 RTS 里其实是三件可算的事

| 维度 | 内容 | 现状 |
|---|---|---|
| **几何** | 成排/成列/等距/留通道 | 只有防线有（`P:351`）；其他族无指标 |
| **可达性与合法性** | 压水/压崖/格角丢路点/LANE 撞位 | 有校验（`P:224` 起源、`P:100` 格角→格心、`P:111` LANE 跳号），但**无量化指标** |
| **保护关系** | 塔在外、厂在内、池边有护矿塔、维修湾在内圈 | **已量**（见下） |

**保护关系的现成基准**（`P:439`，§二十，来自 143 局回放蒸馏）：

- 人类幸存者**遮盖率 100%、裸奔率 0%**——"人类从不让厂当最外层"，AI"工厂建到交战区"确属异类
- 穿插率：小图 26% / 中图 7% / 大图 11%
- 护矿率：小图 50% / 中图 33% / 大图 25%；配塔**时延 p50 20~81s**（"稳固要快"实证）
- 工具：`replay_distill.py` 已含 `protection_stats`（`P:441`）

## 三、缺口的指标（建议新增）

三个指标全部**零 LLM、纯确定性、可从快照 + 回放算**：

| 指标 | 算法 | 治什么 | 靶子来源 |
|---|---|---|---|
| **网格对齐度** | 落点对节距格（暂取 100px）的偏差分布 p50/p90 | 歪扭、不对齐 | 人类回放同族建筑（115 局干净语料，`P:487`） |
| **间距方差** | 同族建筑最近邻间距的方差 | 疏密不均、忽远忽近 | 同上 |
| **碎片度** | 同族建筑的空间聚类数 ÷ 建筑数 | 散成 N 片 = 乱 | 同上 |

配套已有的四个关系指标（遮盖/裸奔/穿插/护矿，`P:439`-`P:441`），合起来才是一套完整的"人类几何基准"。
**有这三个数，"乱"才从主观词变成可回归的量。**

## 四、推进顺序（待做，按序）

1. **先量**（零风险、零 LLM、纯离线）：三指标加进 `replay_distill.py`，在 115 局干净语料上跑出 p50 靶子。
2. **再泛化生成器**：把 `_formation` 从"防线专用"扩成"每个建筑族一套几何"——厂区成排、后勤成列、制造仪群成簇、
   池群 + 护矿塔配对、维修湾内圈。`P:377` ②（"生成器地形变体：沿崖线/绕资源簇/窄口横封"）已给它留了位置。
3. **再升级选址判据**：安全值只管"危不危险"，"整不整齐"正交于它 → 增加**人类基准对照**这一层判据。
4. **顺手补闸门漏**：`P:491` ①（海厂姿态闸 + 选址约束，方案已写好未实施）、`P:496` 遗留老账。

## 五、与 Jev 的关系（交叉结论）

- **Jev 治不了"乱"**：它没有空间感、不产几何、不出坐标。这与 `P:224` 的教训同源——用户洞察=**"LLM 无法精确定位"**
  （bug 史已验证：压水/压崖/格角丢路点/LANE 撞位）。
- Jev 在这件事上**唯一可能的位置**：生成器把候选点位枚举好之后，判"这个位置现场可不可行"。
  **几何、坐标、对齐永远归生成器**，别让它碰。
- 若按本文件 §四 推进，你会发现这一步**根本不需要新模型**——`P:375` ① 早已说清。

## 六、诚实清单

1. 本文件全部为分析，**零实施、零实测**；三个指标只是提案，**未在任何语料上跑过**。
2. **节距口径待确认**：100px 是阵型生成器的甜点节距（`P:351`/`P:366`），不一定是全族通用节距；用作对齐度基准前需你确认。
3. **指标能否替代肉眼判据未验**——"乱"的主诉方是你的眼睛，这套数只是先把主观词变成可比对的量。
4. **碎片度的聚类算法口径未定**（DBSCAN 半径 / 最小点数 / 是否按建筑族分别聚类）。
5. 第 1 步做完之前，第 2/3 步的"改好了没有"**无法判定**——这正是过去"治完还是乱"的机制性原因。
